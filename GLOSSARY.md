# Currency Converter

An offline-first converter between currencies using European Central Bank reference rates.

## Language

**Supported currencies**:
Every currency the rate source publishes a reference rate for; the pool a user can add from.
_Avoid_: All currencies, available currencies

**My currencies**:
The currencies the user has chosen to convert between, offered in both From and To; never fewer than two.
_Avoid_: Currency list, added currencies, selected currencies, watchlist
